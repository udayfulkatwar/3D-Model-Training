# Release Evidence

Nothing has been released from this repository.

A release entry requires:

1. The founder's release authorization (who, date).
2. The acceptance criteria it was tested against (link to PROJECT_REQUIREMENTS).
3. The QA report IDs (link to QUALITY_REPORTS) with passing results.
4. Measured performance on the agreed target devices.
5. The asset licence list for every third-party asset included.
6. Known limitations disclosed to the client.
7. A rollback plan.
